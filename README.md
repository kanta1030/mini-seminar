# aistudio-github-lecture

GitHub ミニレクチャーのワークで使うテンプレートリポジトリです。

## 使い方

1. このページの右上にある緑の「Use this template」を押し、「Create a new repository」を選びます。
2. 「Repository name」に `mini-seminar` と入れ、公開範囲は「Private」を選んで、「Create repository」を押します。
3. できた自分のリポジトリを、SourceTree でクローンします。

このリポジトリを直接書き換えたり、クローンしたりする必要はありません。

## ファイル

- `テンプレートファイル.md`: ワークで書き換えるファイルです。「作成者」に自分の名前を書き、おすすめ動画を書き足していきます。
